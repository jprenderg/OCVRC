# Open Cataclysmic Variable Radio Catalog (OCVRC)

OCVRC is a Python pipeline for building a multi-survey astronomical database from a user-supplied list of sky coordinates. It combines SIMBAD source identification, VLASS and RACS image-based radio measurements, ancillary survey catalog measurements and SQLite export.

The **[Catalog Fields](fields.md)** page documents the complete final database schema.

The pipeline is a general-purpose builder derived from the OCVRC research project. **Its outputs depend on the supplied sources and on external-service availability.**
